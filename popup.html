AutoPrompter

Run selected chats concurrently in managed tabs

When disabled, AutoPrompter ignores its own restriction-message detector. ChatGPT's platform controls still apply, and the extension does not dismiss or bypass them.

Repository continuity and successor chats

Context usage is estimated from visible text. Verified repository handoffs are preferred; if an actual context-limit message arrives before a checkpoint can be made, AutoPrompter opens a best-effort fresh chat using the configured prompt and repository details. Rate limits, account restrictions, and safety blocks still stop the scheduler when the circuit breaker is enabled.

Project Mode foundation

Create durable project state, validate and approve a planner envelope, prepare bounded worker leases, and explicitly send selected assignments after manual model verification. Planner, reviewer, and integrator prompts remain manual.


          

            
            
            
          


          

            Planner and role bootstrap
            
Project creation normally creates or initializes the fixed-role chats, runs the planner, repairs malformed JSON, validates the plan, approves it, and prepares worker assignments automatically. Manual controls remain available as a fallback.

            

              
              
            

            
            
            

              
              
              
            

            

          


          

            Worker lease preparation
            
Prepare leases locally, inspect prompts, or explicitly dispatch them to assigned ChatGPT Web chats after verifying each worker model. Model selection is never automated.

            

              
              
              
            

            
            
            

            
            

            

              Result and independent review
              
Live worker replies are captured automatically. For manual work, paste the exact result envelope for the selected dispatch. A separate reviewer envelope is required before the task can be accepted.

              
              
              
              
              
              
            


            

              Integration evidence
              
After every task is independently accepted, generate an integrator prompt. Integration remains on a non-default branch and project completion requires explicit approval.

              
              
              
              

                
                
                
                
              

              
            


            

              External-action approval queue
              
Approval records user intent only. AutoPrompter does not execute merges, releases, workflow changes, permission changes, deletions, or external side effects.

              

                
                
              

              
              
              
              
              

                
                
              

              
            


            

              Repository restart reconciliation
              
Generate a read-only repository evidence prompt after a browser or extension restart. Reconciliation never accepts tasks or integrations by itself.

              
              
              
              
              

            


            

              ChatGPT selector health
              
Checks currently open ChatGPT tabs for the composer, send/stop controls, new-chat control, notices, and conversation identity. This is not an authenticated end-to-end validation.
